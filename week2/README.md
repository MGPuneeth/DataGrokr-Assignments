# Bank Account OOP and Pandas Analysis

A small Python project demonstrating:

- Object-oriented bank accounts with deposits, withdrawals, transfers, and savings interest.
- Dataset loading, validation, calculated columns, and summary statistics with pandas.

## Setup

```bash
python -m venv .venv
```

Activate the virtual environment, then install the dependency:

```bash
python -m pip install -r requirements.txt
```

## Run

Run the OOP demonstration:

```bash
python main.py
```

Analyze `accounts.csv`:

```bash
python analysis.py
```

Run tests:

```bash
python -m unittest -v
```
